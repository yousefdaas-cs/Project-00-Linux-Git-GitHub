# Why Git Makes Development Easier
Git makes development easier by allowing Seamless Collaboration & Teamwork
 
 **Git safeguards your code:** 
- **Isolation with Branches:** Developers create separate parallel lines of work called branches to write new features or fix bugs without touching the main, stable codebase.

 **Version control tracks history:** 
 - **Keeping logs:** every commit is saved in logs with information about the author, date and the change note
-   **Accountability**: The detailed commit history tracks exactly who made a change, what they changed, and why they changed it. 

**Enable team collaboration**
-   **Conflict Resolution**: Git allows multiple developers to edit the same file at the same time.
- **Provides clear mechanisms to merge and resolve overlapping changes:** using and rolls back and branches.
